# Contributing to `axtree-audit`

## Technical invariants

1. **No external runtime dependencies**: do not add third-party packages to `"dependencies"` in `package.json`. Protocol clients and tree analyzers must rely on standard `fetch`, `WebSocket`, and built-in Node/Bun modules.
2. **Out-of-band inspection**: do not inject DOM mutation scripts into target pages. All accessibility and privacy checks must operate on protocol-level `AXNode` trees and network event streams so pages with strict `Content-Security-Policy` headers can be audited without modification.
3. **REUSE 3.3 licensing**: every source file must start with standard SPDX copyright and `MIT` license headers.

## Generative AI policy (code provenance and copyright hygiene)

In compliance with European copyright law and the **NLnet Foundation Generative AI Policy v2.0 (October 2026)**:

- **Human-authored artefacts only**: contributors may not submit source code, protocol parsers, test fixtures, or documentation generated by Large Language Models (LLMs) or generative coding assistants.
- **Read-only analysis permitted**: using automated static analysis or read-only security linters to identify edge cases is permitted, provided all fixes and code are written and understood by the human author.
- **Verification**: every pull request must include reproducible unit tests runnable offline via `bun test`.
