# Security policy

## Supported versions

| Version | Supported |
| :--- | :--- |
| `0.1.x` | Yes |

## Reporting a vulnerability

Please report vulnerabilities via **GitHub Security Advisories** (`Security -> Advisories -> Report a vulnerability`) or by emailing `contact@koodikiht.dev`.

- **Response SLA**: initial triage within 48 hours.
- **Out-of-band inspection**: `axtree-audit` queries the browser's protocol-level Accessibility Tree (`Accessibility.getFullAXTree`) and network events over a local debugging socket without injecting third-party scripts into the inspected document context.
